# Django List Filterable by Grab Bag of Properties

This repository has an example of how to filter a list of items by matching the value of any property of the item.

Items can have different properties and we avoid scanning the table by using PropertySet and PropertyValue tables to 
make it easier to match all the items that have a value.

This example only matches based on one value _but_ one could split the query and match for any/all of the values. More
complicated matching conditions (ex. address) could also be conceived but are outside the scope of this demo.


# Get Started

To get started run:

```shell
make container-import-test-file
```

You can then view list of items here: http://localhost:8000/ (note by default we use 10K items with no paging, so give 
it a moment). 

# Shut down

To bring everything down (and delete the volume) run:

```shell
make dc-down-delete-volumes
```
